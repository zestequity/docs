# Zest Public API documentation

Source for the Zest Public API documentation site.

This repository is a public mirror of partner-facing documentation
generated from the internal Zest API monolith. Edits should generally be
made upstream and synced here. For partner integration questions, contact
your Zest representative.

## Local preview

```bash
npm i -g mintlify
mintlify dev
```

Site renders at <http://localhost:3000>.

## Sync from upstream

This repo is currently synced manually after partner-API endpoint
changes — see the upstream runbook for details.
